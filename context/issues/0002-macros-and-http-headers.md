# #2 — Перевожу Node-API на макросы и собираю первый HTTP-парсер заголовков

- Источник: https://github.com/kshakirov/n0/issues/2
- Состояние: OPEN
- Рабочая ветка: `dev`
- Снимок обновлён: 2026-09-24

## Задача

Я закончил ручной учебный проход через Node-API и теперь перевожу рабочую границу на `napi-rs` и макрос `#[napi]`. После зачистки легаси начинаю первый полезный байтовый инструмент — разбор стартовой строки и заголовков HTTP-запроса.

## В процессе

- Удаляю учебные типы, сырые `extern "C"`-объявления и ручную регистрацию модуля.
- Оставляю компактный макросный вход `Node Buffer → Rust`.
- Устраняю оставшиеся предупреждения от легаси-кода.
- Определяю минимальный результат парсера: границы method, target и заголовков в исходном буфере.
- Разбираю заголовки напрямую по байтам, без преждевременных строк и копирования.
- Проверяю вызов на данных, пришедших через `node:net`.

## Готово, когда

Node передаёт входной Buffer через макросный интерфейс, Rust находит основные части HTTP-заголовка и возвращает понятный результат, а старого ручного слоя в рабочем коде больше нет.

## Первый комментарий

Я подключил `napi`, `napi-derive` и `napi-build`, добавил первый экспорт через `#[napi]` и проверил, что проект собирается. Ручной учебный FFI пока ещё лежит рядом и даёт предупреждения `dead_code` — уберу его следующим изменением внутри этого тикета, после чего оставлю один чистый макросный путь.

## Первый сквозной проход парсера

Я разделил Rust на чистое ядро, Node-addon и отдельный runner. HTTP Buffer приходит в ядро как неизменяемый `&[u8]`, а компактная таблица результата — как изменяемый `&mut [i32]`. Со стороны Node это исходный `Int32Array`, поэтому Rust пишет результат прямо в него без промежуточной копии.

Первый автомат распознаёт метод `GET`. Его код задаётся enum `Method` с `#[repr(u8)]` и попадает в первую ячейку таблицы. Оба входа проверены: runner вызывает ядро напрямую, а Node через addon получает `[6, 0, 0, 0]` и тот же объект Buffer.

Дальше я добавлю остальные методы, разделю конец строки и конец всего блока заголовков, затем начну заполнять следующие ячейки таблицы признаками нужных заголовков и размером тела.
