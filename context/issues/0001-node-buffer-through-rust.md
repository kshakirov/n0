# #1 — Провожу Node Buffer через Rust без копирования

- Источник: https://github.com/kshakirov/n0/issues/1
- Состояние: CLOSED
- Рабочая ветка: `dev`
- Снимок обновлён: 2026-09-10

## Задача

Я хочу довести первый настоящий байтовый путь через границу Node-API. Node передаёт `Buffer`, Rust распознаёт его, получает адрес и длину, читает байты и изменяет их на месте. Node после возврата видит результат в том же объекте.

## Готово, когда

- Rust отличает `Buffer` от других JavaScript-значений.
- Rust получает указатель и длину через Node-API.
- Безопасная Rust-функция работает с `&mut [u8]`.
- Изменение байтов видно в Node без копирования.
- Проверка `output === input` возвращает `true`.
- Весь опыт запускается одной командой `make run`.

## Уже сделано

- Экспортирована функция `isBuffer`.
- Аргумент получен через `napi_get_cb_info`.
- Тип проверен через `napi_is_buffer`.
- Машинный `bool` преобразован в JavaScript Boolean через `napi_get_boolean`.
- Через `napi_get_buffer_info` получены адрес данных и длина Buffer.
- Проверены ненулевая длина и ненулевой указатель.
- Первый байт прочитан непосредственно из памяти Buffer.
- На границе FFI построен временный изменяемый срез `&mut [u8]`.
- Обработка байтов вынесена в безопасную Rust-функцию.
- Байты изменены непосредственно в памяти исходного Node Buffer.
- В Node подтверждено, что `output === input`: копии Buffer не создаются.
- Текущий маршрут проверен командой `make run`.

## Завершение

- Все критерии готовности выполнены. Тикет закрыт 2026-09-10.
