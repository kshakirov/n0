# N0

[English](Home.md)

N0 — мой экспериментальный сервер обработки байтов: Node.js отвечает за TCP и события, Rust разбирает HTTP через N-API. Я двигаюсь небольшими проверяемыми шагами и измеряю изменения, прежде чем делать выводы о скорости.

## Архитектура

В реализации разделены чистое Rust-ядро, Node-addon и самостоятельный Rust runner. Входные буферы неизменяемые. Fixed- и chunked-тела обрабатываю потоково, копируя полезные участки блоками в свежую арену на каждый вызов. Сохранять ли части тела, решает приложение.

Общая фаза запроса отделена от состояния автомата тела; состояние сохраняется между вызовами. Парсер экспериментальный: текущие тесты не доказывают полную поддержку HTTP.

## Исследования и текущая работа

Сейчас делаю прототип компиляции маршрутов: сохраняю буквальные байты, заменяю параметры резервными областями для захвата и подготавливаю байтовые метаданные. Сопоставление и исключение кандидатов ещё не реализованы. В задуманном исполнителе независимые рабочие копии маршрутов сокращаются по мере чтения URI; результат содержит совместимые полные совпадения с исходными RouteID.

Дальнейшие направления — проход по заголовкам через `memchr` и маршрутизация во время разбора URI. Это пока исследования, а не реализованные возможности.
